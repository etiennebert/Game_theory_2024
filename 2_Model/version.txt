GTAP-AEZ version 7 (GTAPv7-aez) model

--------------------------------------------------
I. File description: gtapv7-aez.zip 
--------------------------------------------------
File: gtapv7-aez.zip
Description: 
 This zip file contains the GEMPACK-based code of the GTAPv7-aez model and files to 
 run GTAP-AEZ model simulations in RunGTAP.

 The theory behind the standard GTAP model is described in:   
    Erwin L. Corong, Thomas W. Hertel, Robert A. McDougall, Marinos E. Tsigas, 
    and Dominique van der Mensbrugghe. The Standard GTAP Model, Version 7. 
    Journal of Global Economic Analysis, [S.l.], v.2, n.1, p. 1-119, june 2017. 
    Available at: https://jgea.org/ojs/index.php/jgea/article/view/47
			  or  dx.doi.org/10.21642/JGEA.020101AF.
